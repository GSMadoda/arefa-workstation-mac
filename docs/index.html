System

This is the in-browser functional-equivalence build of the AREFA workstation. The conversation model runs on your device via WebGPU — the page is static, there is no backend, no API key, and nothing you type leaves your machine. That keeps AREFA's sovereign posture: it is hosted on the internet, but every conversation stays local to whoever is using it.

Not the audited source. The in-browser model is an MLC-compiled build of Qwen2.5 — functionally the same family the source runs (qwen2.5:7b), but not the exact Ollama quantization or digest 845dbda0ea48. This build does not reproduce the frozen (f7e2317a…) or successor (85c7f4e9…) fingerprints and must not be represented as exact historical identity.

Prefer a fully-local copy?

A self-contained build that runs the exact source model (qwen2.5:7b via Ollama) on your own machine, no download of a browser model, works offline:

# needs Python 3 (ships with macOS)
git clone https://github.com/GSMadoda/arefa-workstation-mac.git
cd arefa-workstation-mac
python3 arefa_workstation.py
