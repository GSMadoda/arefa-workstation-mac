Run the full workstation locally

This page is the same app, served from GitHub and talking to the model on your Mac. For a fully self-contained copy that needs no CORS setup and no internet, run it locally:

# needs Python 3 (ships with macOS)
git clone https://github.com/GSMadoda/arefa-workstation-mac.git
cd arefa-workstation-mac
python3 arefa_workstation.py

It opens at http://127.0.0.1:8973/ on your machine. Cloned files are not quarantined, so it never trips the “unidentified developer” warning, and it works offline.

System

This is the macOS functional-equivalence build of the AREFA workstation — the system’s described architecture, not its audited source. It does not reproduce the frozen (f7e2317a…) or successor (85c7f4e9…) fingerprints and must not be represented as exact historical identity.

Hosted-conversation security note. This page runs from github.io and talks to the model on your machine. For that to work you allow this origin in Ollama’s CORS, which lets this externally-hosted page drive your local model. The model still runs locally and nothing is sent to the internet, but the driving code is hosted, not cloned. If that tradeoff matters, use the local build on the “Run locally” tab instead.
