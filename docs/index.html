About this build

AREFA is a private assistant. This page runs the model in your own browser using WebGPU — there's no server, no account, no API key, and nothing you type is sent anywhere. Chat needs a recent Chrome or Edge on a computer; the Mining tab works in any browser.

This is a functional-equivalence build of AREFA — the same Qwen2.5 model family the source system runs, adapted to the browser. It is not the audited AREFA source and does not reproduce its fingerprints.

Run it on your own machine

Want the exact source model (qwen2.5:7b via Ollama), offline, self-contained?

git clone https://github.com/GSMadoda/arefa-workstation-mac.git
cd arefa-workstation-mac
python3 arefa_workstation.py
