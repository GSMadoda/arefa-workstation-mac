About

AREFA runs entirely in your browser. No server, no account, no key. Nothing you type is sent anywhere. The assistant needs Chrome or Edge on a computer; Mining works anywhere.

A functional-equivalence build — the same Qwen2.5 model family as the source, adapted to the browser. Not the audited AREFA source.

Run it on your Mac

git clone https://github.com/GSMadoda/arefa-workstation-mac.git
cd arefa-workstation-mac
python3 arefa_workstation.py
